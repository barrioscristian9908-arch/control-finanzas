# Control Finanzas

Aplicación web diseñada para ayudarte a gestionar tus finanzas personales de manera simple y eficiente. Cuenta con una interfaz intuitiva que facilita el registro, seguimiento y análisis de tus movimientos financieros.

---

## 🚀 Funcionalidades

### 💼 Cuentas

Permite crear y administrar múltiples cuentas (efectivo, banco, billeteras virtuales, etc.), facilitando el control de tu dinero en distintos medios y manteniendo tus saldos organizados.

---

### 🗂️ Categorías

Podés registrar categorías tanto para ingresos como para egresos, lo que te permite clasificar y entender mejor tus movimientos financieros.

---

### 🎯 Metas

Este módulo te ayuda a establecer y alcanzar objetivos financieros. Incluye:

* Creación de metas con un monto objetivo
* Registro de aportes a metas específicas
* Visualización de los aportes realizados
* Seguimiento del progreso mediante una barra visual

---

### 🔄 Movimientos

Permite registrar diferentes tipos de movimientos para llevar un control detallado de tus finanzas. También incluye la opción de realizar transferencias entre cuentas, asegurando que tus saldos se mantengan actualizados.

---

### 📊 Reportes

Ofrece una visualización clara de tu situación financiera mediante gráficos simples e intuitivos. Podrás analizar tu progreso mensual y entender mejor tus gastos.
